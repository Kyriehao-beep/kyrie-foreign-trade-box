# 装箱、CBM 与计费重量计算器

> 新增的纯本地工具（无 AI、无后端、无鉴权、无付费接口、无实时运价查询）。
> 目标：帮外贸人按产品数量与纸箱尺寸，快速算出总箱数、合计体积(CBM)、毛/净重、体积重、计费重量，并估算 20GP / 40GP / 40HQ 的装载率；结果可一键写入装箱单或带入报价助手。

## 1. 输入

| 输入 | 单位 | 说明 |
| --- | --- | --- |
| 产品数量 | 件 | 整批总件数 |
| 每箱装量 | 件/箱 | 单箱装多少件 |
| 纸箱长 / 宽 / 高 | cm（每箱） | 单箱外尺寸 |
| 每箱毛重 / 净重 | kg/箱 | 单箱重量 |
| 托盘数量（可选） | 个 | 不栈板可留空，尺寸随之留空 |
| 托盘长 / 宽 / 高 | cm | 单托尺寸 |
| 运输方式 | 快递 / 空运 / 海运 | 决定体积重折算 |
| 预计总运费（可选） | 元（整单） | 用于折算平均运费/件，带入报价助手 |

## 2. 输出

- **总箱数**：`ceil(数量 / 每箱装量)`；不能整除时额外提示「尾箱 N 件」。
- **单箱体积**：`长×宽×高(cm) / 1,000,000`（m³）。
- **合计体积 / 总 CBM** = 单箱体积 × 总箱数。
- **合计毛重 / 净重** = 每箱重量 × 总箱数。
- **体积重**：快递 `总 CBM × 200`、空运 `总 CBM × 167`（kg）；海运不计体积重 → 显示「不适用」。
- **计费重量** = `max(实重, 体积重)`；海运直接取实际毛重。
- **柜型装载估算**：`总 CBM / 柜型容量`，见下表（仅体积估算）。
- **平均运费/件** = `预计总运费 / 产品数量`（未填则不显示、按钮禁用）。

## 3. 关键常量（行业常用经验值，仅估算）

| 项目 | 取值 |
| --- | --- |
| 20GP 可用容积 | 33 m³ |
| 40GP 可用容积 | 67 m³ |
| 40HQ 可用容积 | 76 m³ |
| 快递体积重系数 | 1 CBM ≈ 200 kg（等价于单件 L×W×H / 5000） |
| 空运体积重系数 | 1 CBM ≈ 167 kg（等价于单件 L×W×H / 6000） |
| 海运 | 不计体积重，计费重量 = 实际毛重 |

> 柜型容量与体积重系数均为经验值，实际装载还受限重、货物形状、托盘与绑扎方式影响，UI 已显著标注「仅为估算，以船公司/承运人为准」。

## 4. 与现有工作流的联动

### 4.1 写入装箱单
- 点击「写入装箱单」→ 读取现有装箱单(PL)草稿（`loadDraft('PL')`），不存在则用 `createEmptyDraft('PL')` 新建。
- 写入**首行** `LineItem`：
  - `quantity` = 产品数量
  - `cartons` = 总箱数
  - `netWeight` = 合计净重 / 产品数量（**每件**净重）
  - `grossWeight` = 合计毛重 / 产品数量（**每件**毛重）
  - `volume` = 总 CBM / 产品数量（**每件**体积，m³）
- 因为现有 `calculateTotals` 对 `netWeight/grossWeight/volume` 按件累计、对 `cartons` 直接求和，这样写入后装箱单「总箱数 / 总净重 / 总毛重 / 总体积」恰好等于计算器的整批结果。
- 写入成功后在计算器内提示，并给出「前往单据中心」入口（用户在单据中心选择「装箱单(PL)」查看）。

### 4.2 带入报价助手
- 填写「预计总运费」后，「带入报价助手」按钮可用。
- 点击 → 跳转到 `/quote?freight=<平均运费/件(元，4 位小数)>`。
- `QuoteAssistant` 读取 `?freight` 后，自动把 `unitIntlFreight` 设为该值并切到 `CIF`（海运/空运/快递运费均计入 CIF）。

### 4.3 本地持久化
- 计算器输入保存在独立键 `ktb_carton_cbm`（不影响任何其它草稿键）。
- 「清空」按钮二次确认后清空输入并删除该键。
- 「加载示例」填入一组示例数据（2400 件 / 50 件每箱 / 60×40×30 cm / 毛重 18 kg / 净重 16 kg）。

## 5. 校验与边界

- 拒绝负数（产品数量/每箱装量/尺寸/重量/运费）。
- 每箱净重不能大于每箱毛重。
- 任意字段为空或 0 都不会产生 `NaN` / `Infinity`（统一 `safeNum` 塌缩为 0）。
- 每箱装量为 0 或数量为 0 → 总箱数 0，不报错。
- 超大数量（如 1000 万件）不产生 `Infinity`。

## 7. 自测结果

- `tsc -b`：通过，无类型错误。
- `vitest run`：全部通过（新增 24 例 + 原有 141 例 = **165 例**）。
- `vite build`：成功，CSS 含暗色覆盖层。
- 响应式（Puppeteer，1440 / 768 / 390）：**无横向溢出**（scrollWidth == innerWidth），暗色模式正常应用。
- 集成验证：
  - 加载示例后总箱数 = 48 箱；写入装箱单后 `items[0].cartons=48`、`netWeight=0.32`，提示「已写入装箱单草稿」。
  - `?freight=4.1667` 跳转到报价助手后，`单件国际运费` = 4.1667、条款切到 CIF。
- 控制台错误：0。
