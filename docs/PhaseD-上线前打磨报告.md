## 三、首用体验（Quick Start）

- 首页 Hero「免费开始使用」打开 `Quick Start` 对话框（「想从哪里开始？」）。
- 三个入口：① 体验示例报价单（`/documents?sample=qt`）② 创建空白单据（`/documents`）③ 先试试快速报价（`/quote`）。
- **示例数据隔离**（已用浏览器端断言验证）：
  - 通过 `?sample=qt` 进入时仅内存态，暂停自动保存；
  - 顶部显示「示例数据 · 仅演示，未保存到本地」琥珀色提示；
  - 示例公司名为虚构值（鸿运家居用品（示例）有限公司 / Sunrise Trading Co., Ltd.（示例））；
  - **不覆盖已有真实草稿**（断言：已有 `REAL-DRAFT-XYZ` 草稿在示例模式下保持原值）；
  - 仅点击「保存为我的草稿」才写入本地（若有真实草稿会 `confirm` 二次确认）；
  - 「退出示例」恢复该类型的真实草稿。

## 四、上下文定制服务提示（会话级只展示一次）

- 触发点：报价结果、PDF/Excel 导出成功、PI→CI/PL 生成成功（非阻断内联卡片）。
- 同一会话（`sessionStorage` 守卫）只出现一次，避免重复打扰。
- **修复一处移动端缺陷**：原实现把提示放在预览栏 `aside`，而该栏在 `<lg`（<1024px，即平板/手机）且处于「填写」视图时 `hidden`，导致移动端看不到提示。已将其移至**始终可见**的快捷操作区，并用 `!sampleMode` 守卫（示例模式不弹）。

## 五、无障碍 / 语义（节选）

- 非表单 CTA 显式 `type="button"`；表单控件 `htmlFor`+`id` 配对。
- 联系页二维码对话框：`role="dialog"`、`aria-modal="true"`、`aria-labelledby`、关闭按钮 `aria-label="关闭"`、Esc 关闭、显式 `width/height=208`。
- 可见 `focus-visible` 焦点环；图标按钮带 `aria-label`。
- 异步状态用 `aria-live="polite"`；无 `transition-all`；`prefers-reduced-motion` 已由 `index.css` 守卫。
- 移动端底部导航保留 `safe-area-inset` 安全区。

1. **PDF / Excel 实际文件落盘**：无头浏览器未断言文件下载二进制，但导出逻辑由单元测试覆盖，且 e2e 已验证「导出→提示触发」与「PI→CI/PL→草稿落盘」（均走 `saveDraft` 通道）。建议上线前在真实浏览器手动导出一次确认版式。
2. **真实 AI / 后端鉴权**：本阶段按约定不含后端、AI、支付，相关能力未启用、也未在 UI 宣传。
3. **定价一致性**：收费文案全部取自 `staticConfig.ts` 单一源（`TRIAL_DAYS=14`、买断 ¥299 等），已断言关键文案在页面存在；历史违禁文案（永久免费 / 未来所有工具 / ¥199 等）已从代码移除。
4. **构建环境提示（仅本沙箱）**：本环境的 `vite build` 在清空 `dist` 时触发了「安全删除批量守卫」（≥50 文件需确认）。这是 WorkBuddy 沙箱的安全机制，**用户本机 `npm run build` 不受影响**。若需在本沙箱重建，构建到全新目录再覆盖 `dist/client` 即可绕过。
